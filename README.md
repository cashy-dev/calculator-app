# 🧮 Advanced Calculator (JavaScript)

A professional calculator built with **vanilla JavaScript**.

## ✅ Features
- Keyboard support (0–9, + − × ÷, Enter, Backspace, Esc)
- Calculation history (click a result to reuse it)
- Percent & sign toggle (±)
- Memory buttons (MC, MR, M+, M−)
- Clean UI (responsive)
